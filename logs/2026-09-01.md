- 레시피 검색 및 찜(북마크) 상단 표시 로직 구현 (`df5712b`)
  - `RecipeSearchMapper` / `RecipeSearchService` / `RecipeSearchServiceImpl` / `RecipeSearchController` 신규 추가
  - `GET /recipe/search?keyword=&user_id=` 엔드포인트 신설
  - 키워드로 레시피명(`RCP_NM`)을 LIKE 검색하고, `recipe_bookmark` 테이블을 LEFT JOIN해 로그인 유저가 찜한 레시피(`is_bookmark`)를 검색 결과 상단에 정렬해 노출
    ```xml
    <select id="selectRecipeSearch" resultType="com.sist.web.vo.RecipeSearchVO">
      SELECT r.RCP_SEQ as rcp_seq, r.RCP_NM as rcp_nm,
             r.ATT_FILE_NO_MAIN as att_file_no_main,
             r.INFO_ENG as info_eng, r.RCP_PAT2 as rcp_pat2,
             CASE WHEN b.BOOKMARK_ID IS NOT NULL THEN 1 ELSE 0 END as is_bookmark
      FROM RECIPE r
      LEFT JOIN recipe_bookmark b
      ON r.RCP_SEQ = b.RECIPE_ID AND b.user_id =#{user_id}
      WHERE r.RCP_NM LIKE '%'||#{keyword}||'%'
      ORDER BY is_bookmark DESC, r.RCP_SEQ
    </select>
    ```
    (파일: `src/main/resources/mybatis/mapper/recipesearch-mapper.xml`, 커밋: `df5712b`)
